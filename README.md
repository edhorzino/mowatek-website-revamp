# Mowatek Nigeria Limited website

Static HTML, CSS and JavaScript generated by a small Node build script, with a Vercel enquiry API using Resend. Use Node 22.x and install dependencies with npm ci.

## Build and preview

- npm run build: regenerates dist from public, templates, content and configuration.
- npm test: builds, checks local links/assets/SEO and runs mocked email-handler tests. No production emails are sent.
- npm run serve: serves the static preview on port 8080; it never sends real emails.
- node tools/serve.mjs 8080 --mock-form: enables local form responses for interactive tests. reject@example.com simulates a provider failure; nonjson@example.com simulates an unexpected response; other addresses simulate acceptance. Never deploy this development server as the production backend.
- python tools/test-browser.py: optional Playwright/Chromium regression suite against the mock preview. Set MOWATEK_TEST_URL for another port. Requires a separately installed Playwright and browser.

## Editing

- site.config.json: public domain, contact information, partner and client logos. Never put secrets here.
- src/content.mjs: five service definitions, FAQ, photos and captions.
- build.mjs: page layouts and About copy.
- src/templates.mjs: header, footer and shared components.
- public/assets/css/site.css: existing design plus the client carousel styles.
- public/assets/partners and public/assets/clients: logo files. Configure names and files in site.config.json; the blank client image is deliberately excluded.
- src/hosting.mjs: security headers and legacy redirects. After changing hosting rules, domain, form endpoint or analytics, run npm run configure:hosting and commit the regenerated vercel.json.

## Production hosting

Vercel configuration is committed in vercel.json and uses npm run build with dist as output. The api/quote.js serverless function remains at the repository root. Uploading only dist to a static host will not provide the email endpoint. For another host, deploy an equivalent Node backend or configure a compatible JSON endpoint and update the browser contract.

Set RESEND_API_KEY in Vercel project environment variables. QUOTE_FROM_EMAIL is optional; its default is Mowatek Quotes <enquiries@quotes.mowatek.com>. The sender domain must be verified in the same Resend account. The notification recipient is config.contact.email, currently info@mowatek.com. Do not commit credentials. See .env.example.

The form submits JSON, validates on the browser and server, checks a honeypot and minimum submission time, escapes notification HTML and includes a plain-text version. Success requires the provider to return an accepted email ID; provider acceptance is distinct from inbox delivery. A best-effort limit permits five valid attempts per client IP per ten minutes in each function instance. Configure Vercel Firewall if a shared limit across instances is needed.

Before launch, submit a real enquiry on the deployed site and verify the message reaches the recipient. Check Resend delivery logs, domain verification and spam folders if necessary. Local mocks do not prove production inbox delivery.

## URLs and caching

The canonical site is https://mowatek.com. The five services are /water-treatment/, /wastewater-effluent-treatment/, /procurement-maintenance/, /consulting/ and /training/. Removed and renamed URLs redirect to their replacements or /services/. Vercel also redirects www to the canonical host; both domains must be assigned in the Vercel dashboard.

The build generates sitemap.xml, robots.txt, canonical tags and social previews. It also creates Netlify/Cloudflare headers and redirects, and Apache .htaccess rules for static hosting. Existing asset names are not fingerprinted, so Vercel revalidates assets rather than caching them as immutable for a year.
